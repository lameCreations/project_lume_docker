# 📦 Project Lume Data Cartridges

**Project Lume Data Cartridges** are pre-packaged, zero-dependency columnar dataset bundles (`.parquet`) designed for instant, portable demonstrations, CTF investigations, benchmark replays, and offline evaluation.

---

## 🎯 How Data Cartridges Work

Project Lume is powered by a high-performance **DuckDB Columnar Lakehouse**. Unlike legacy SIEMs that force you to ingest, index, and duplicate terabytes of logs into proprietary inverted indexes, Project Lume queries Parquet directly at vectorized memory speed:

1. **Zero Indexing Time:** Drop any `.parquet` file into `./Dropzone_Inputs/` or `./data_vaults/slices/`.
2. **Instant Availability:** DuckDB immediately binds or unifies the files under unified views (e.g. `cim_network`, `zeek_conn`, `cim_auth`).
3. **Plug-and-Play Removal:** Delete or move the file out of the folder, and it disappears cleanly from the database with zero leftover database bloat.

```text
[ Data Cartridge (.parquet) ]
            │
            ▼  (drop into ./Dropzone_Inputs/ or ./data_vaults/slices/)
[ Project Lume Lakehouse Engine ]
            │
            ├─► Instant Sub-Second Vectorized SQL Queries
            ├─► 24 Deterministic LBI Math Receipts (Z_r, MAD, JSD, CUSUM)
            └─► Real-Time Command Center Threat Hunting & CTF Analysis
```

## 🚀 Quickstart: Loading a Cartridge into Project Lume

### Method 1: Dropzone (Recommended)
Copy the downloaded `.parquet` cartridge directly into your running container's dropzone:
```bash
# Place into the Dropzone_Inputs folder next to your docker-compose.yml:
cp cartridges/corelight_bots_cartridge.parquet ./Dropzone_Inputs/
```
Project Lume's autonomous `dropzone_watcher` will instantly ingest and register the telemetry into your DuckDB lakehouse.

### Method 2: Direct Lakehouse Querying
You can query the cartridge directly from DuckDB or the Lume Search Bar without importing:
```sql
SELECT sourcetype, COUNT(*) 
FROM 'cartridges/botsv1_attack_cartridge.parquet' 
GROUP BY 1 ORDER BY 2 DESC;
```
